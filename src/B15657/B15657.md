# 풀이에 대한 설명
N개의 수 중에서 M개를 고르되, 같은 수를 여러 번 골라도 되고, 비내림차순이어야 하는 문제입니다.
배열을 먼저 정렬한 뒤 DFS로 조합을 뽑았습니다. 같은 수를 반복 선택할 수 있어야 하므로 재귀 호출 시 i+1이 아닌 i를 넘겼습니다. 중복 수열이 나올 수 있어서 TreeSet으로 자동 정렬 + 중복 제거를 했습니다.

# 시행 착오
처음에 i+1로 넘겼다가 같은 수를 두 번 못 고르는 문제가 생겼습니다. 문제를 다시 읽어보니 "같은 수를 여러 번 골라도 된다"는 조건이 있어서 i로 바꿨습니다.
그리고 처음엔 중복 체크를 안 해서 같은 수열이 여러 번 출력됐는데, TreeSet 써서 한 번에 해결했습니다.
